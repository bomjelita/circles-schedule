# Расписание работы кружков и секций

**Программный модуль для автоматизации учёта внеурочной деятельности в школе.**

---

## Описание

«Расписание работы кружков и секций» — это настольное приложение с графическим интерфейсом, разработанное для автоматизации рабочих процессов заместителя директора по воспитательной работе МБОУ Чистоозерная СОШ № 2 Чистоозерного района Новосибирской области. Модуль позволяет оперативно вести учёт кружков и секций дополнительного образования, контролировать расписание их работы и формировать сводную информацию.

### Основные возможности
- Добавление нового кружка/секции с указанием названия, руководителя, дней недели, времени начала и окончания, номера кабинета и возрастной группы.
- Просмотр полного списка кружков в табличном виде.
- Поиск кружков по названию, руководителю или дню недели.
- Редактирование данных существующего кружка.
- Удаление кружка из списка.
- Автоматическое сохранение данных в файл JSON.

---

## Архитектура

Модуль реализован по принципу многоуровневой архитектуры с разделением ответственности:

- `CircleInfo.cs` — модель данных (класс, описывающий структуру записи о кружке).
- `DataManager.cs` — компонент управления данными (чтение/запись JSON через Newtonsoft.Json).
- `ScheduleLogic.cs` — компонент бизнес-логики (добавление, удаление, поиск, редактирование).
- `MainForm.cs` — главная форма с таблицей DataGridView и кнопками управления.
- `CircleEditForm.cs` — диалоговая форма добавления/редактирования кружка.
- `Program.cs` — главный файл запуска.

## Требования

- .NET Framework 4.8 или выше.
- Операционная система: Windows 7 / 8 / 10 / 11.
- Внешние зависимости: Newtonsoft.Json (устанавливается через NuGet).
- Среда разработки: Microsoft Visual Studio 2026.

---

## Установка и запуск

1. Скачайте или клонируйте репозиторий:
   git clone https://github.com/bomjelita/circles-schedule.git
2. Откройте файл `CirclesSchedule.csproj` в Microsoft Visual Studio 2026.
3. Дождитесь автоматического восстановления NuGet-пакета Newtonsoft.Json.
4. Нажмите F5 или кнопку «Запуск» для компиляции и запуска программы.
